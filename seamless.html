Jolt Widget - シームレスログイン (Phase 2 STEP5 / HMAC)

← メインページに戻る

使い方

ベンダーがバックエンドで生成した HMAC 署名を window.jolt.referrer に渡すと、フォーム入力・マジックリンク認証をスキップして即認証される挙動を確認するページです。

署名はプログラム単位のシークレット（管理画面「クリエイティブ > ウィジェット > シームレスログイン設定」で発行）を使って、以下の形式で計算します。

メッセージ: {email}|{customer_id}|{program_id}|{timestamp} を HMAC-SHA256 → hex。timestamp は ±5 分以内（UNIX 秒）。

Node.js で署名 + テスト URL を生成する例:

const crypto = require("crypto");
const secret = process.env.JOLT_REFERRER_SECRET; // 管理画面で発行したプログラム単位シークレット
const programId = "01XXXXXXXXXXXXXXXXXXXXXXXX";
const email = "user@example.com";
const customerId = "";                 // 任意（空文字でも可。署名計算には必ず含める）
const timestamp = Math.floor(Date.now() / 1000);
const message = `${email}|${customerId}|${programId}|${timestamp}`;
const signature = crypto.createHmac("sha256", secret).update(message).digest("hex");
const qs = new URLSearchParams({ program: programId, email, customer_id: customerId, timestamp: String(timestamp), signature });
console.log(`seamless.html?${qs.toString()}`);

出力された URL（このページのファイル名 + クエリ）を開くと、ウィジェットが認証済み状態で表示されます。

※ 署名は ±5 分で失効するため、生成したらすぐ開いてください。失効・不一致の場合はメアド入力フォーム（未認証）にフォールバックします。

※ このページが参照する widget.js は stg CDN（https://tag.stg.jolt.me/widget/v1/widget.js）です。シームレスログイン配線を含む jolt-tag のビルドが stg にデプロイ済みであることが前提です。
